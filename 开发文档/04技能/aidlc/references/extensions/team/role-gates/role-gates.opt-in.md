# 角色门禁 — Opt-In

**Extension**: Role Gates

## Opt-In Prompt

以下问题会在需求分析阶段的澄清问题里自动出现：

```markdown
## Question: 审批门禁粒度
本项目的阶段门禁要设成哪种？

A) 仅需求审批 — 需求出来后停下等你批准，之后全自动跑完（**默认**；需求要人把关、实现可托付）
B) 关键三关 — 只在「需求定稿 / 设计定稿 / 代码合入」三处硬停，其余阶段自动通过但报备（2-3 人团队）
C) 每阶段都停 — 每个阶段结束都要人工批准，最严
D) 只在交付验收 — 中间不停，最后一次验收
E) 全自动 — 不设门禁，自答澄清问题，跑完整流程后交验收报告（小工具/原型用）
X) 其他（请在 [Answer]: 后说明）

[Answer]: 
```

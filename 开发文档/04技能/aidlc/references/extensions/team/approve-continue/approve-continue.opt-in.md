# Approve / Continue 分离 — Opt-In

**Extension**: Approve / Continue Separation

## Opt-In Prompt

以下问题会在需求分析阶段的澄清问题里自动出现：

```markdown
## Question: Approve / Continue 分离
本项目是否需要多人协作，且不同阶段由不同角色负责（例如产品批需求、工程师写代码）？

A) 需要 — 门禁只保留「请求修改 / 批准」两项，批准后必须由下一角色回复「继续」才能推进
B) 不需要 — 单人作业，门禁保留「请求修改 / 批准 / 批准并继续」三项
X) 其他（请在 [Answer]: 后说明）

[Answer]: 
```
